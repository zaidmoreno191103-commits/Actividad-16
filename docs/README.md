# Task Manager – Equipo ESTRELLA UMIZUMI

Aplicación web sencilla para gestionar tareas, desarrollada como parte del laboratorio T16 "Del requisito al producto".

## Funcionalidades

- ✅ Crear tarea
- ✅ Mostrar tareas
- ✅ Marcar tarea como completada
- ✅ Eliminar tarea
- ✅ Editar tarea (CR-001)
