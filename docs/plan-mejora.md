# Plan de mejora del proceso

## Objetivo

Subir del nivel 2 (Gestionado) al nivel 3 (Definido).

## Situación actual

El equipo gestiona el trabajo con un tablero y backlog, usa Git para control de versiones y documenta cambios. Sin embargo, no hay procesos estandarizados, métricas ni mejora continua formal.

## Mejoras propuestas

| Área | Situación actual | Mejora propuesta |
|---|---|---|
| Gestión | Backlog en Trello | Definir plantilla estándar de historias de usuario |
| Desarrollo | Commits descriptivos | Adoptar Conventional Commits y revisión por pares |
| Pruebas | Manuales | Automatizar con Jest + Cypress |
| Cambios | CR-001 documentado | Plantilla formal de CR + comité de cambios |
| Métricas | No se usan | Medir velocidad, bugs por sprint, lead time |
| Calidad | Revisión informal | Checklist de calidad antes de cada entrega |

## Prioridades

1. Automatizar pruebas.
2. Definir métricas de proceso.
3. Formalizar retrospectivas.
4. Estandarizar plantillas de documentación.

## Resultado esperado

Con estas mejoras, el equipo podrá medir su desempeño, repetir procesos exitosos y mejorar continuamente, alcanzando el Nivel 3 de CMMI (Definido).
