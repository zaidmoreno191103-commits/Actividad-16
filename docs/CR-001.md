# CR-001 – Editar una tarea

## Solicitante

Cliente

## Descripción

Permitir editar una tarea existente después de haberla creado.

## Motivo

Los usuarios necesitan corregir errores ortográficos o actualizar la descripción de sus tareas sin tener que eliminarlas y volver a crearlas.

## Análisis de impacto

| Factor | Impacto | Justificación |
|---|---|---|
| Alcance | Medio | Se añade una nueva funcionalidad. |
| Tiempo | Medio | Requiere modificar 3 archivos y probar. |
| Costo | Bajo | Sin costos adicionales de infraestructura. |
| Calidad | Medio | Riesgo de bugs en la lógica de render. |
| Recursos | Bajo | El equipo puede asumirlo. |
| Riesgo | Medio | Puede afectar tareas existentes. |

## Decisión

Aprobado

## Justificación

El cambio aporta valor directo al usuario, es viable técnicamente y su impacto es controlable. Se implementará dentro del Sprint 1 como extensión.

- script.js
